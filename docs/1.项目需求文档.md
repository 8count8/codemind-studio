## **1. 项目背景**
### 1.1 业务目标
- **解决的问题**： 
  传统编程学习平台缺乏实时AI反馈与个性化学习路径规划，导致学习效率低、错误修正不及时。
- **目标用户**： 
  编程初学者、计算机专业学生、希望提升开发技能的从业人员。

### 1.2 项目范围
- **包含的功能**：
  - 动态主题门户
  - AI代码审查与注释生成
  - 实时编程反馈
  - 智能错题诊断
  - 个性化学习路径推荐
  - 用户能力分析
  - 题库系统
  - 代码练习环境集成

## **2. 功能需求**
### 2.1 核心功能列表
| 功能模块         | 优先级（MVP/高/中/低） | 描述                                                   |
| ---------------- | ---------------------- | ------------------------------------------------------ |
| **用户认证**     | MVP                    | 用户可通过邮箱/密码注册、登录，支持密码重置。          |
| **首页+门户**    | MVP                    | 动态主题切换+核心功能入口（AI审查/题库/个人中心）      |
| **AI代码审查**   | 高                     | 代码注释生成与质量评估（规范/性能/安全），支持分栏对比 |
| **实时编程反馈** | MVP                    | 代码提交后实时返回语法/逻辑错误标记                    |
| **题目搜索系统** | 高                     | 支持按语言/难度/知识点标签组合筛选编程题               |
| **错题诊断引擎** | 中                     | 自动分析错误模式并关联相似题目推荐                     |
| **题目收藏管理** | 中                     | 用户可创建自定义题单并设置分类标签                     |

### 2.2 详细功能描述
#### **功能名称**：用户注册  
- **功能描述**： 
  用户通过填写邮箱、密码和手机号完成注册。  
- **输入/输出**：  
  - 输入：邮箱、密码（至少8位）、手机号（可选）。  
  - 输出：注册成功提示邮件，数据库记录用户信息。  
- **业务流程**：  
  1. 用户访问注册页面。  
  2. 填写表单并提交。  
  3. 系统验证邮箱唯一性，发送验证邮件。  
  4. 用户点击邮件链接激活账户。

#### **功能名称**：首页门户

- **功能描述**：
  集成动态主题切换与核心功能导航入口的两个展示界面
- **输入/输出**：
  - 输入：用户主题偏好设置
  - 输出：渲染对应主题的导航卡片与快速入口
- **业务流程**：
  1. 用户访问平台门户
  2. 系统加载预设/自定义主题方案
  3. 用户点击门户页面的进入按钮
  4. 跳转到首页
  5. 动态生成包含AI审查/题库/个人中心等功能的导航卡片

#### **功能名称**：AI代码质量审查

- **功能描述**：
  对用户提交代码进行多维度质量审查与优化建议生成
- **输入/输出**：
  - 输入：用户代码文件（支持拖拽/编辑器输入）
  - 输出：分栏对比视图（原始代码 vs 优化建议）+质量评分报告
- **业务流程**：
  1. 用户通过拖拽或编辑器提交代码
  2. 系统调用AI引擎进行规范/性能/安全分析
  3. 生成带注释的优化版本并高亮关键差异点

#### **功能名称**：错题诊断引擎

- **功能描述**：
  基于历史练习记录定位用户知识薄弱点并提供强化建议
- **非功能性要求**：
  - 诊断结果需关联至少3道同类题目
  - 支持导出错题分析报告（PDF格式）

#### **功能名称**：题库筛选系统

- **功能描述**：
  多级联动过滤的编程题库，支持难度范围选择和收藏态管理

#### **功能名称**：实时答题系统

- **功能描述**：
  双栏式编程练习环境，集成语言切换和自动保存功能
- **业务流程**：
  1. 用户选择编程语言并编写代码
  2. 系统每30秒自动保存草稿至本地缓存
  3. 提交时触发AI评分流程
  4. 可视化展示运行时指标和优化建议
