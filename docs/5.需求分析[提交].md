### 第一章 需求分析

#### 一、开发背景

传统编程学习平台（如 Codecademy、LeetCode）存在反馈延迟、缺乏个性化路径规划等痛点。本项目旨在构建智能化学习平台，通过**实时 AI 反馈**和**动态学习路径优化**提升学习效率。目标用户为编程初学者、计算机专业学生及技能提升从业者，覆盖从基础语法到复杂项目开发的全学习周期。

#### 二、竞品分析

| **维度**       | **Codecademy** | **LeetCode** | **本项目**                                 |
| -------------- | -------------- | ------------ | ------------------------------------------ |
| **AI 功能**    | 基础语法纠错   | 无 AI 辅助   | **代码质量审查 + 注释生成 + 实时错误标记** |
| **个性化推荐** | 固定课程路径   | 刷题排行榜   | **基于能力矩阵的动态学习路径规划**         |
| **实时反馈**   | 提交后批量反馈 | 测试用例验证 | **提交检测后逐行错误提示**                 |
| **错题管理**   | 无智能分析     | 错题本功能   | **错误模式诊断 + 同类题目强化推荐**        |
| **社区支持**   | 论坛讨论       | 题解分享     | **代码审查报告导出 + 成就系统**            |

**核心优势**：

1. **三维度 AI 分析**：代码规范、性能、安全性全面审查；
2. **动态出题机制**：根据用户薄弱点生成自适应试题；
3. **实时交互体验**：代码输入与反馈同步进行，支持 WebSocket 进度跟踪。
