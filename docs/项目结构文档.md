### 后端架构

```
CMS/
├── app/
│   ├── __init__.py
│   ├── api/                  # 所有API端点
│   │   ├── v1/              # 版本控制
│   │   │   ├── __init__.py
│   │   │   ├── auth.py      # 认证相关API
│   │   │   ├── users.py     # 用户管理API
│   │   │   └── ai.py        # AI功能API
│   │   ├── schemas/         # 数据模型定义
│   │   │   ├── user.py
│   │   │   └── ai.py
│   │   └── core.py          # API全局配置
│   ├── models/              # 数据库模型
│   │   │   └──ai/
│   │   ├── __init__.py
│   │   ├── favorites_models_db  #收藏题目供service调用model
│   │   ├── favorites_topics     # 收藏题目低层数据库逻辑
│   │   ├── import_question.py   # 后端题目导入数据库程序
│   │   ├── question_db.py       # 题目列表的底层数据库逻辑
│   │   ├── question_model.py    # 题目列表供service调用model
│   │   ├── save_problem.py      # 保存AI的生成的题目
│   │   ├── user_code.py         # 用户的代码保存至数据库
│   │   ├── user.db              # 数据库建表语句
│   │   ├── user_login.py        # 用户登录、注册相关处理
│   │   └── user_operation_records.py  # 用户文件处理、API接口传回的文件的数据库存储
│   ├── service/            # 业务逻辑
│   │   ├── __init__.py     
│   │   ├── algorithm_service.py      # AI生成的生成的题目的业务逻辑
│   │   ├── FavoriteService.py        # 收藏题目业务逻辑
│   │   ├── processing_operations.py  # 代码审查相关处理逻辑
│   │   ├── QusetionSerice.py         # 题目列表的业务逻辑
│   │   └── UserLoginService.py       # 用户登录
│   ├── utils/               # 工具类
│   │   ├── security.py      # 安全相关
│   │   └── validators.py    # 数据验证
├──.env                      # 发送验证码邮箱相关信息
├── config.py                # 配置文件
├── requirements.txt
└── run.py
```

### 前端

```
CMS/
├── app/
│   ├── static/         
│   │   ├── css/
│   │   ├── js/
│   │   └── favicon.ico
│   │
│   └── templates/       
│       └── index.html 
└── ...
```

| 目录/文件          | 职责                                                  | 所属 MVC 层       |
| :----------------- | :---------------------------------------------------- | :---------------- |
| `app/api/`         | 存放所有 API 路由和控制器（RESTful 接口）             | **Controller 层** |
| `app/models/`      | 数据库模型和核心数据逻辑（如 SQLAlchemy 模型）        | **Model 层**      |
| `app/service/`     | 业务逻辑服务层（复杂操作封装，如用户认证、数据处理）  | **Model 层扩展**  |
| `app/utils/`       | 工具类（日志、验证、加密等辅助功能）                  | **跨层工具**      |
| `app/templates/`   | Jinja2 模板文件（前端页面）                           | **View 层**       |
| `app/static/`      | 静态资源（CSS/JS/图片）                               | **View 层辅助**   |
| `run.py`           | 应用启动入口（通常调用 `app/__init__.py` 的工厂函数） | **启动脚本**      |
| `requirements.txt` | 项目依赖库列表                                        | **环境配置**      |
| `docs/`            | 项目文档（如 API 文档、设计说明）                     | **辅助文档**      |
| `.gitignore`       | Git 忽略规则                                          | **版本控制**      |
| `venv/`            | Python 虚拟环境（建议添加到 `.gitignore`）            | **本地环境**      |
